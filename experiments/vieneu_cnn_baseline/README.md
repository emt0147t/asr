# VieNeu-TTS 4-Class CNN Keyword Spotting Baseline

## 1. Overview

This directory contains the first four-class convolutional neural network (CNN) baseline trained on the verified 1,000-utterance synthetic Vietnamese command dataset generated by local open-source VieNeu-TTS v3 Turbo (`experiments/synthetic_kws_dataset_vieneu_1000/`).

Target classes:
- `TRAI` (Trái) — Target index 0
- `PHAI` (Phải) — Target index 1
- `LEN` (Lên) — Target index 2
- `XUONG` (Xuống) — Target index 3

> [!IMPORTANT]
> **Strict Governance Status**:
> - Dataset subjective human intelligibility verification remains **`PENDING_HUMAN_LISTENER_VERIFICATION`** (Phase 25 80-clip listening evaluation pending completion).
> - Baseline acoustic generalization status is **`NOT_VALIDATED_ON_NATURAL_SPEECH`**.
> - This baseline establishes in-distribution acoustic separability across unseen synthesized voices; it does not constitute clinical or production deployment readiness on field human speech recordings.

## 2. Model Architecture & Acoustic Features

### Acoustic Preprocessing (`AudioPreprocessor`)
- **Sampling Rate**: 16,000 Hz, mono PCM WAV (1.0 second duration = 16,000 samples)
- **Time-Frequency Representation**: 40-channel Log-Mel Filterbank Spectrogram
  - FFT size: 512 samples (~32 ms)
  - Window length: 400 samples (25 ms Hann window)
  - Hop length: 160 samples (10 ms hop)
  - Frequency range: 20 Hz to 7,600 Hz
  - Spectrogram dimensions: `(Batch, 1, 40, 101)`
  - Per-spectrogram instance standardization (zero mean, unit variance)

### Classifier Network (`VietnameseKWSNet`)
A compact 4-block 2D Convolutional Neural Network (~137k parameters):
1. **ConvBlock 1**: Conv2d(1 -> 32, kernel=3, padding=1) + BatchNorm2d + ReLU + MaxPool2d(2, 2) -> `(32, 20, 50)`
2. **ConvBlock 2**: Conv2d(32 -> 64, kernel=3, padding=1) + BatchNorm2d + ReLU + MaxPool2d(2, 2) -> `(64, 10, 25)`
3. **ConvBlock 3**: Conv2d(64 -> 128, kernel=3, padding=1) + BatchNorm2d + ReLU + MaxPool2d(2, 2) -> `(128, 5, 12)`
4. **ConvBlock 4**: Conv2d(128 -> 128, kernel=3, padding=1) + BatchNorm2d + ReLU -> `(128, 5, 12)`
5. **Head**: AdaptiveAvgPool2d((1, 1)) -> Dropout(0.3) -> Linear(128, 4) -> Logits `(Batch, 4)`

## 3. Dataset Splits & Isolation

Splits are strictly partitioned by synthetic preset speaker identity (`voice_id`), guaranteeing zero voice leakage across splits:
- **Train Split**: 680 utterances (170 per class, 17 distinct voices)
- **Validation Split**: 160 utterances (40 per class, 4 distinct voices)
- **Held-Out Test Split**: 160 utterances (40 per class, 4 distinct voices)

Total: 1,000 utterances, 25 unique voices. All audio files are bit-exact, verified against SHA-256 hashes, with zero clipping and zero phoneme truncation.

---

## 4. Multi-Seed Training Protocol

- **Seeds**: 42, 43, 44
- **Optimizer**: AdamW (lr=1e-3, weight_decay=1e-4)
- **LR Schedule**: Cosine Annealing (T_max=40, eta_min=1e-6)
- **Loss Function**: Cross-Entropy with non-finite loss detection
- **Epochs**: 40
- **Batch Size**: 32
- **Training-Only Augmentations**:
  - Random temporal shift: ±25 ms (±400 samples)
  - Random amplitude gain: [0.9, 1.1]
- **Model Selection**: Checkpoint with highest validation macro F1 (`val_macro_f1`).

## 5. Execution Commands

### Training
```bash
# Run multi-seed training
python experiments/vieneu_cnn_baseline/train.py --all-seeds

# Run single seed
python experiments/vieneu_cnn_baseline/train.py --seed 42
```

### Evaluation
```bash
# Evaluate best checkpoint on held-out test split
python experiments/vieneu_cnn_baseline/evaluate.py --checkpoint experiments/vieneu_cnn_baseline/checkpoints/best_checkpoint_seed42.pt
```

### Testing
```bash
# Run pytest test suite
pytest tests/test_vieneu_cnn_baseline.py -v
```
